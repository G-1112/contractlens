# 条款级准确率实测（合成样例集）

> ⚠️ **数据性质**：测试集为 `scripts/build_evalset.py` 程序合成的样例，
> 由规则库关键词套用句式模板生成，标注由构造过程确定。
> **不代表真实合同分布**，用于规则引擎回归度量，引用时须标注「合成样例」。
> 样本：50 份合同，
条款总数 297 条（含标注风险 276 条）。
> 运行环境：本机 mock 模式（无 LLM Key），规则引擎与法规检索全量生效。

## 总体指标

| 指标 | 数值 | 计算式 |
|---|---|---|
| 精确率 P | **0.9288** | TP/(TP+FP) = 274/(274+21) |
| 召回率 R | **0.9928** | TP/(TP+FN) = 274/(274+2) |
| F1 | **0.9597** | 2PR/(P+R) |
| 等级准确率 | **0.9745** | 等级一致数/TP = 267/274 |
| TP / FP / FN | 274 / 21 / 2 | — |

## 误报（FP）来源分析

| 判定来源 | FP 数 |
|---|---|
| llm_only | 21 |

说明：`llm_only` 的误报主要来自 mock 模式的确定性启发式（无 LLM Key 时的降级策略），
接入真实 LLM 后该部分会被语义判定替换，指标需重新实测。
