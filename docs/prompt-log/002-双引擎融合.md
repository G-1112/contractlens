# Prompt 链 002 · 双引擎融合定级（FR-07）

> 记录"提问 → AI 建议 → 引导修 Bug"的完整链。

## 提问

> 我有两套判定结果：规则引擎（确定性，可能误报）和大模型（语义，但会抽风判低）。
> 怎么把两者合成一个最终风险等级？我担心 AI 判低分的时候，把真正危险的条款放跑了。

## AI 建议

AI 给出"规则抬下限"的融合策略：

```
if 规则命中 and LLM 等级 >= 规则等级: 取 LLM，来源=both
elif 规则命中 and LLM 等级 < 规则等级: 取规则，来源=rule_override（需复核）
else: 取 LLM，来源=llm_only
```

核心思想：**规则命中即抬高等级下限**，AI 判低分也不能低于规则等级。

## 我如何采纳并改进

1. 增加第四态 `rule_only`（LLM 判定缺失/失败降级时，纯规则兜底）；
2. `rule_override` 时标记 `needs_review=True`，UI 提示"建议人工复核"；
3. `risk_type` 在 LLM 未给出类型时，用规则命中的类型兜底（避免雷达归类混乱）。

## 引导修 Bug

写单测时发现：`llm=None`（LLM 失败、无判定）时，`llm_level` 默认"无"，
导致第二个分支 `_compare("无", "高") < 0` 恒成立，**规则命中却 LLM 缺失**的条款被误判为
`rule_override` 而非 `rule_only`。我向 AI 描述"LLM 判定缺失时分支走错了"，AI 指出
第二个条件缺少 `llm is not None` 守卫，修复后四态全部通过单测。
