# Prompt 链 001 · 条款切分（FR-03）

> 记录"提问 → AI 建议 → 引导修 Bug"的完整链。

## 提问

> 我有一份中文合同，想按「章/条/款/项」把条款切分出来做风险分析。
> 合同里的编号有这几种：`第X章`、`第X条`、`一、`、`1.1`、`（一）`。
> 我还需要每条保留页码和坐标，方便前端高亮。用 Python 怎么写？

## AI 建议

AI 给出用正则 + 层级栈的方案：

```python
PATTERNS = [
    (r'^第[一二三四五六七八九十百]+章', 1),
    (r'^第[一二三四五六七八九十百]+条', 2),
    (r'^[一二三四五六七八九十]+、',     2),
    (r'^\d+\.\d+(\.\d+)?',            3),
    (r'^（[一二三四五六七八九十]+）',    4),
]
```

要点：把"编号起始行"作为块的锚点，其后所有无编号行归入该块；用栈维护最近祖先，栈顶即父节点。

## 我如何采纳并改进

1. 编号模式按优先级排序，先章后条后款后项，避免误匹配；
2. 块内多行用中文连接（`""` 而非空格），中文合同习惯无空格；
3. `id` 用 `c-<页码>-<序号>` 生成，稳定可追溯；
4. 无编号的开头文字（如合同标题）归为"前言"块，不丢内容。

## 引导修 Bug

切分后测试发现：`_join_lines` 对英文/数字条款用空串连接会粘成一团（如 `1.1适用范围`）。
我反馈"含英文或数字的条款连起来不对"，AI 定位到连接符选择问题，
最终改为按"中文占比"动态决定用空串还是空格（`_mostly_cjk`），并补上对应单测。
