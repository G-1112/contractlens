## 提问

> 审查出高风险条款后，我想生成一段"可以直接发给房东/HR"的谈判话术。
> 要求：语气礼貌、有依据、给出替代方案。这个 Prompt 怎么写才能不翻车？

## AI 建议

AI 给出三点约束：
1. 引用条款原文关键表述（"合同第 5 条写的是……"）；
2. 给出替代方案（改写后的条款）；
3. 控制长度（100 字内一段话，不分点不加标题），避免变成啰嗦的小作文。

并给出系统 Prompt：

```
你是合同谈判助手……语气礼貌、有依据、不指责对方；引用条款原文关键表述；
给出具体替代方案；100 字以内，一段话。
```

## 我如何采纳并改进

1. 增加离线确定性模板 `_TALK_TEMPLATE`，无 LLM 时也能生成可用话术（复现性）；
2. 话术按风险等级排序，高风险优先，最多 5 条；
3. 从条款文本正则提取"第X条"作为引用定位（`_extract_ref`）。

## 引导修 Bug

初版话术对"改写建议为空"的条款（如缺失检测类）生成了"能不能改成「」"这种空槽。
我反馈"改写为空时话术读不通"，AI 建议在 `suggest`/`rewrite` 为空时回退为通用协商措辞
（"与对方协商明确双方权利义务"），修复后模板始终有内容。
