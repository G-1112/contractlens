# 条款级准确率实测（真实合同标注集）

> **数据性质**：真实合同 + 逐条标注（来源登记见 data/evalset_real/provenance.json）。标注方式：AI 预标注（助手）+ 人工复核待确认。样本量小、来源分布单一，置信区间宽，引用时须同时给出样本量与口径。
> 样本：23 份合同，
标注条款 439 条（风险 144 条），其中 TP+FP+FN 215 条、真负例 224 条。
> 运行环境：本机 真实 LLM（deepseek-chat，并发=8）——与线上部署同口径。

## 总体指标

| 指标 | 数值 | 计算式 |
|---|---|---|
| 精确率 P | **0.6359** | TP/(TP+FP) = 124/(124+71) |
| 召回率 R | **0.8611** | TP/(TP+FN) = 124/(124+20) |
| F1 | **0.7316** | 2PR/(P+R) |
| 等级准确率 | **0.6371** | 等级一致数/TP = 79/124 |
| TP / FP / FN | 124 / 71 / 20 | — |

## 误报（FP）来源分析

| 判定来源 | FP 数 |
|---|---|
| llm_only | 69 |
| both | 2 |

说明：`llm_only` 误报来自 LLM 直接判定（未获规则或检索佐证即标记风险），
`rule_override` 来自规则抬级与 LLM 判定不一致。两者是收敛迭代的主要对象。
