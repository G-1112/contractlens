# 条款级准确率实测（真实合同标注集）

> **数据性质**：真实合同 + 逐条标注（来源登记见 data/evalset_real/provenance.json）。标注方式：AI 预标注（助手）+ 人工复核待确认。样本量小、来源分布单一，置信区间宽，引用时须同时给出样本量与口径。
> 样本：23 份合同，
标注条款 439 条（风险 144 条），其中 TP+FP+FN 349 条、真负例 90 条。
> 运行环境：本机 mock 模式（无 LLM Key，规则引擎与法规检索全量生效）。

## 总体指标

| 指标 | 数值 | 计算式 |
|---|---|---|
| 精确率 P | **0.3807** | TP/(TP+FP) = 126/(126+205) |
| 召回率 R | **0.8750** | TP/(TP+FN) = 126/(126+18) |
| F1 | **0.5305** | 2PR/(P+R) |
| 等级准确率 | **0.4841** | 等级一致数/TP = 61/126 |
| TP / FP / FN | 126 / 205 / 18 | — |

## 误报（FP）来源分析

| 判定来源 | FP 数 |
|---|---|
| llm_only | 155 |
| rule_override | 44 |
| both | 6 |

说明：`llm_only` 的误报主要来自 mock 模式的确定性启发式（无 LLM Key 时的降级策略），
接入真实 LLM 后该部分会被语义判定替换，指标需重新实测。
