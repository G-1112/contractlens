# 迭代 v2 · 双引擎融合：给黑盒加约束

## 重构前

规则引擎能抓"硬伤"，但语义层面的风险（措辞是否公平、是否过度约束）覆盖不到；
而直接信任大模型又担心它"判低分放跑高风险条款"。

## 重构后

引入 LLM 语义判定 + 融合层，规则抬高下限：

```
规则命中 && LLM 等级 >= 规则等级 → both
规则命中 && LLM 等级 < 规则等级 → rule_override（需复核）
规则命中 && LLM 判定缺失       → rule_only
无规则命中                     → llm_only
```

- LLM 输出用 JSON Schema + Pydantic 强约束，温度 0；
- `evidence` 强制原文照抄，堵住幻觉；
- LLM 失败自动降级，整条流水线不崩溃。

## 收益

- 覆盖规则与语义两类风险，且规则误报可被"AI 复核"标签提示；
- 融合策略 100% 可断言（`tests/test_fusion.py` 四态全覆盖）；
- UI 区分「规则命中」与「AI 判断」，不冒充权威。
