# 检索器对照实验（R-RAG-01，第十五轮）

> 实测日期：2026-11-24 22:54；条款集：真实标注集 439 条（439 条抽样条款，与评测同源）；盲评：deepseek-chat（t=0），
> 每条 A/B 顺序对调评两轮，两轮一致才计胜负、不一致记平——消除位置偏好。
> 候选 A = 现行字符 bigram TF-IDF（与产品同算法离线复现）；候选 B = BM25（k1=1.5, b=0.75，bigram 词项）。

| 指标 | TF-IDF（现行） | BM25 |
|---|---|---|
| 盲评胜场 | 68（15.5%） | 219（49.9%） |
| 决定性对局胜率 | 23.7% | 76.3% |
| Top-3 空结果 | 2 条 | 2 条 |

## 结论（第十五轮 · 含端到端终裁）

**盲评：BM25 显著胜出**——决定性对局胜率 76.3%（219/287，TF-IDF 仅 23.7%）。

**但端到端实测否决了升级**：把检索器切换为 BM25 后重跑同一评测
（dev / holdout / 全量三口径同向），F1 反而下降：

| 口径 | TF-IDF（v13） | BM25（试升级） | ΔF1 |
|---|---|---|---|
| dev（13 份） | 0.7219 | 0.6818 | −0.040 |
| holdout（10 份，盲测） | 0.7101 | 0.6977 | −0.012 |
| **全量（23 份，对外口径）** | **0.7240** | **0.6954** | **−0.029** |

**最终裁决：回滚 TF-IDF**。回滚后复测全量 F1 0.7316（LLM t=0 波动范围内，
与 0.7240 一致），性能基准同步复测 331 条款检索 131.2 → 65.2 ms（提速 50.3%）。

这一负结果的价值在于方法本身：**检索质量的代理指标（盲评）提升 ≠ 端到端
指标提升**。BM25 的 IDF 加权偏好稀有词匹配的片段，语义上"更相关"，但下游
LLM 判定更依赖 TF-IDF 检出的规则性提示片段。以端到端 F1 为最终裁决标准，
避免了一次"看起来更好、实际更差"的升级。实验脚本 `scripts/retrieval_ab_test.py`
与全部数据留档可复核。

## 方法说明与局限

- LLM 盲评衡量的是「法规片段对条款审查的支撑度」，与端到端 F1 相关但不等价；
- BM25 为离线独立实现，未改动产品代码；升级决策另行评估；
- 语料小（140 条法规），BM25 的 IDF 估计方差大，结论仅适用于本项目语料。
