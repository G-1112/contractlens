## 法条引用可溯源性

- 裸 LLM 共引用法条 **294** 处，其中能在本项目 140 条权威法规库（国家法律法规数据库来源）中按「法规名+条号」定位的 **173** 处（58.8%）
- 无法定位 121 处——即通用大模型在该标注集上存在 121 处**无法立即溯源核验的法条引用**
- 契约眼的法条引用 100% 来自法规检索命中（引用必在库内），并逐条展示原文——
  这是对抗法条幻觉的结构性手段，而非提示词约束。

## 方法说明与局限

- 裸 LLM 采用与流水线相同的 JSON 输出约束（仅保证可解析，不提升判定能力）；
- 单模型单次运行；通用大模型结论会随版本波动，本实验记录的是当时实测；
- 契约眼数值与裸 LLM 同日同批实测（当前流水线 v14 分级标尺口径）。
