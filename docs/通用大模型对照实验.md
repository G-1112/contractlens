# 通用大模型直接审查对照实验（R-EVAL-02）

> 实测日期：2026-11-24 20:32；模型：deepseek-chat（temperature=0）。
> 条款集与判定口径与 `docs/eval-accuracy-real.md` 完全一致（23 份合同 / 439 条 / 风险 144 条），可直接对比。
> 裸 LLM 组不提供规则库、不提供法规检索、不提供融合策略——即「把合同丢给通用大模型」。

## 条款级判定对比（同一标注集）

| 组 | P | R | F1 | TP | FP | FN |
|---|---|---|---|---|---|---|

## 法条引用可溯源性

- 裸 LLM 共引用法条 **306** 处，其中能在本项目 140 条权威法规库（国家法律法规数据库来源）中按「法规名+条号」定位的 **176** 处（57.5%）
- 无法定位 130 处——即通用大模型在该标注集上存在 130 处**无法立即溯源核验的法条引用**
- 契约眼的法条引用 100% 来自法规检索命中（引用必在库内），并逐条展示原文——
  这是对抗法条幻觉的结构性手段，而非提示词约束。

## 方法说明与局限

- 裸 LLM 采用与流水线相同的 JSON 输出约束（仅保证可解析，不提升判定能力）；
- 单模型单次运行；通用大模型结论会随版本波动，本实验记录的是当时实测；
- 契约眼数值为 v13 收敛后同日实测（`docs/eval-accuracy-real.md`），与裸 LLM 同批运行；
