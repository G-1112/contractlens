# 真实集标注判定标准（2026-11-02）

> 用途：`data/evalset_real/labels.json` 的等级口径。标注方式：AI 预标注 + 人工复核。
> 依据：《民法典》合同编（667–702 借款/保证）、最高法民间借贷司法解释（LPR 四倍）、
> 《个人信息保护法》、以及合同审查实务中的「显失公平 / 加重对方责任」判断。

## 等级定义

| 等级 | 判定标准 | 典型情形 |
|---|---|---|
| **高** | 违反现行法强制性规定或司法解释上限；或显失公平致条款可能无效 | 年利率超 LPR 四倍、利息预先从本金扣除、日违约金 ≥ 千分之一（年化 36%+）、约定保证合同独立于主合同（违民法典 682）、未约定保证方式却按连带（违民法典 686）、押金概不退还、单方任意解除且不退费、放弃诉讼权利 |
| **中** | 明显加重一方责任或权利义务不对等，但未直接违法 | 连带保证叠加保证金并要求授权划扣账户、单方监督/检查权无边界、担保费不退、违约金比例空白且「不足以弥补仍需补偿」、「实现债权全部费用」无上限、预先追偿（代偿前即可诉） |
| **低** | 轻微不对等或表述模糊，建议完善 | 政策调整无需征得同意、通知期限空白、单方指定送达方式、解释权归一方 |
| **无** | 常规条款，无实质风险 | 主体栏、定义、生效、份数、合理争议解决、不可抗力、常规通知义务 |

## 风险类型（写入 risk_type，须在 annotate_real.py 的 VALID_TYPES 内）

利率 / 违约金 / 担保 / 隐私 / 个人信息 / 还款 / 缺失 / 解除 / 争议 / 费用 / 期限 / 格式条款 / 免除 / 其他

## 免责声明

本口径用于**评测标注**，不构成法律意见；边界条款（如「保证范围含实现债权费用」）按
「是否显著加重一方责任」从宽认定，宁可多标「中」也不轻易判「无」——漏标会高估系统召回。
